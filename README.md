# 请假证明一键生成 Skill（乙方案）

面向东北电力大学青年志愿者服务站的请假证明批量生成工具。输入学生名单 + 活动信息，一键输出格式与模板一致的 Word 请假证明，多页时**每一页末尾都有落款**。

## 快速开始

```powershell
cd 请假证明生成skill
python -X utf8 generate.py "样例数据\上课请假-名单.csv"
python -X utf8 generate.py "样例数据\分寝室请假-名单.csv"
```

输出：`上课请假证明-20261011.docx` / `分寝室请假证明-20261011.docx`（含同名 PDF 预览）。

## 目录

```
请假证明生成skill/
├── SKILL.md                  # Skill 定义（豆包技能入口）
├── generate.py               # 生成器（唯一入口）
├── 请假证明模板填写规范.md     # 详细规范 v0.5
├── 样例数据/
│   ├── 上课请假-名单.csv      # 名单（列头：学院,姓名,班级,学号）
│   ├── 活动信息-上课请假.csv   # 活动键值对
│   ├── 分寝室请假-名单.csv
│   └── 活动信息-分寝室请假.csv
└── 模板/                      # 放置 上课请假模板.docx / 分寝室请假模板.docx
```

## 依赖

```powershell
pip install python-docx openpyxl pymupdf
```

渲染核验需要本机装有 **Microsoft Word 或 WPS**（脚本依次尝试 `Word.Application` →
`KWps.Application` → `Wps.Application`）。

`generate.py` 按 `模板/` 子目录（或同目录）查找模板，缺失时会明确报错。
> 模板为二进制文件、含学校公文抬头，仓库不放；从仓库克隆后需自行把原件放入 `模板/`。

## 输入格式

- **CSV**：名单文件 + 同目录 `活动信息*.csv`（键值对，键见 SKILL.md）。
- **XLSX**：Sheet「名单」+ Sheet「活动信息」。
- **JSON**：`{"info":{…}, "headers":[…], "students":[… ]}`。

## 校验保障

生成后自动渲染 PDF 并逐页核验：每页题头图片、每页落款齐全、末内容为日期、无孤行/空页；
不通过则按「每页容量 -1」单调收敛后重渲染（≤15 轮）。

其他要点：

- **节次自动换算**：名单里含「请假节次」列且未提供 `periods` 时，自动换算成
  `五六节课（13:30-15:05）、七八节课（15:30-17:05）` 这类表述，支持一份数据混多种节次。
- **成品不保留黄色高亮**：高亮只是模板里「此处需替换」的标记。
- **表格列宽自适应**：按本批名单最长内容现算并锁定固定布局，保证每列只占一行；
  放不下时降字号，不删减任何信息。

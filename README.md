# 请假证明一键生成 Skill（乙方案）

面向东北电力大学青年志愿者服务站的工具集，含两个功能：

1. **请假证明一键生成**：输入学生名单 + 活动信息，一键输出格式与模板一致的 Word 请假证明，多页时**每一页末尾都有落款**。
2. **课表空闲时段汇总**：输入一批学生课表截图（每人一张，红框标注识别区域、蓝框标注班级+姓名），批量识别无课时间段，汇总成值班排班用的《空闲时间表》xlsx（含存疑复核清单）。

## 快速开始

```powershell
# 功能一：请假证明
python -X utf8 generate.py "样例数据\上课请假-名单.csv"
python -X utf8 generate.py "样例数据\分寝室请假-名单.csv"

# 功能二：课表空闲汇总（先按 SKILL.md 流程识图生成 roster_json，再汇总）
python -X utf8 scripts/build_roster.py --json-dir "sample_timetables\roster_json"
```

输出：`上课请假证明-20261011.docx` / `分寝室请假证明-20261011.docx`（含同名 PDF 预览）；`空闲时间表_YYYYMMDD.xlsx`（三张表：汇总 / 存疑复核 / 逐人明细）。

## 输入格式

**功能一（请假证明）**
- **CSV**：名单文件 + 同目录 `活动信息*.csv`（键值对，键见 SKILL.md）。
- **XLSX**：Sheet「名单」+ Sheet「活动信息」。
- **JSON**：`{"info":{…}, "headers":[…], "students":[… ]}`。

**功能二（课表空闲汇总）**
- 一批课表截图（每人一张）→ 识别阶段按《课表空闲识别规范.md》产出每人一个 JSON → 汇总脚本合并。

## 校验保障

- 功能一：生成后自动渲染 PDF 并逐页核验：每页题头图片、每页落款齐全、末内容为日期、无孤行/空页；不通过自动缩减页容量重渲染（≤6 轮）。
- 功能二：每张图识别后回读自检；遮挡/异常一律存疑不臆断；JSON 可人工修正后重跑汇总。
